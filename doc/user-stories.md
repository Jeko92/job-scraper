## Personas

* Job Seeker: Platform User, Candidate
* Prospect: Potential Platform User
* Platform Owner: System Admin and Stakeholder for Platform success
* Consultant: Optional for the future

## User Stories

### MVP

As a Job Seeker, I want to be able to select multiple locations, because I'm open for relocation. 

As a Job Seeker, I want to look at job opportunities in different fields, because I need a change in my life.

As a Job Seeker, I want to apply filters and sort the results, so that they fit better to my criteria. 

As a Job Seeker, I want to edit my profile, because recent updates in my CV or skill-set are not in my profile yet. 

As a Job Seeker, I want to explore the platform’s job opportunities with the least details, so I can decide if it’s worth using it.

### Backlog

As a Job Seeker, I want to check available jobs in a different city, because I have to relocate for personal reasons. 

As a Job Seeker, I want to be able to select multiple locations, because I'm open for relocation. 

As a Job Seeker, I want to be proactive but not full-time with my search, because my current industry is changing.

As a Job Seeker, I want to look at job opportunities in different fields, because I need a change in my life.

As a Job Seeker, I want to expand my search for jobs, because I'm unsatisfied or unsuccessful at the typical portals and websites. 

As a Job Seeker, I want to be informed when new opportunities that fit to my profile are available, because this is a lower priority or I don't have the time to login every day.

As a Job Seeker, I want to apply filters and sort the results, so that they fit better to my criteria. 

As a Job Seeker, I want to exclude certain industries or companies, because I've made bad experiences with them or they mismatch my moral system. 

As a Job Seeker, I want to select some criteria that I expect from a workplace or opportunity, because my level allows me to set standards. 

As a Job Seeker, I want to upload my CV, so that the platform can fill-in my skills and experience.

As a Job Seeker, I want to edit my profile, because recent updates in my CV or skill-set are not in my profile yet. 

As a Job Seeker, I want to have an overview of the jobs I've visited, because I changed my mind about something and want to apply to a job that previously didn't seem to be a match. 

As a Job Seeker, I want to download the jobs I applied to, so that I can forward this information to the social system.

As a Job Seeker, I want to mark listings for later, because I don't have time at the moment.

As a Job Seeker, I want to mark listings as important, so that I'm reminded to keep track on the process. 

As a Job Seeker, I want to mark listing as applied-to, so that I won't see the same job in my search. 

As a Job Seeker, I want to mark listings as uninteresting to me, so that I won't see (this kind of) job in my search. 

As a Job Seeker, I want to add notes to jobs, because sometimes I need the extra personal text to keep track of my thoughts. 

As a Job Seeker, I want to see how well a job fits to me, so that I can prioritize where to apply first.

As a Job Seeker, I want to change how the Platform notifies me, because I don't like to receive too many emails. 

As a Job Seeker, I want to customize the frequency of notifications (daily, weekly), so I’m not overwhelmed.

As a Job Seeker, I want to see the start date and application deadline, because I need three months before I can start a new job. 

Optional: As a Job Seeker, I want to generate a tailored cover letter based on my profile and the job description, so I can apply quickly.

---

As a Prospect, I want to explore the platform’s features without creating an account, so I can decide if it’s worth signing up.

As a Prospect, I want to see testimonials or success stories from other job seekers, so I can trust the platform’s effectiveness.

As a Prospect, I want to understand the pricing model, so I know what to expect before committing.

---

As a Platform Owner, I want to know how many jobs are currently running and how many tokens are being spent, to that I can write a report and/or plan for expansion. 

As a Platform Owner, I want to be alerted about critical system health, so that I can mitigate immediately.

As a Platform Owner, I want to build and view system KPIs so that I can make business, budget, or marketing decisions accordingly.
